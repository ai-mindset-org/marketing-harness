# недельная петля превращает результаты пачки в ТЗ на следующую
- триггер: каждую неделю пачка делается с нуля, выводы прошлой недели теряются в чате
- доказательство: «снапшот всех креативов → разметка содержания → паттерны пачки → действие по каждому креативу → один markdown становится ТЗ»
- шаг: пятничный срез из одной таблицы и одной строки решения на единицу
- контр-тезис: на малом объёме паттерны шумные, решения держим гипотезами
- форматы: F2
