# перечень источников спринта

Живой перечень: что прошло, где лежит конспект, какие внешние наборы подключены. Новая строка появляется в день, когда [[{skill} lms-ingest]] записал конспект.

## правило
Сырой транскрипт в набор не кладём. В `sources/` лежит конспект с таймкодами `[ч:мм:сс]` на 30–120 строк: механики, цифры, инструменты, цитаты спикера. Причина: один транскрипт весит до 100 КБ, содержит имена участников и забивает контекст агента ([[{rule} sources-and-consent]], [[{rule} boundaries]]). Оригинал остаётся в LMS по идентификатору `lms:<slug>`, агент забирает его инструментом `lms_transcript`, когда нужна проверка цитаты.

## как вносить строку
1. `lms-ingest` создаёт конспект `sources/{source} <спикер> <тема> – <дата занятия>.md`, во frontmatter `source: lms:<slug>`, `speaker`, `recorded`, `owner`, `usage_rights`, `sensitive`;
2. строка попадает в таблицу «занятия» с датой, темой и ссылкой на конспект;
3. цифры конспекта уходят на сверку в [[{context} truth-pack]];
4. внешний набор добавляется строкой во вторую таблицу после решения фаундера ([[{role} founder]]).
