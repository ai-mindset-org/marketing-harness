# Контент-стратегия AI Mindset · 28.07.2026

Конспект стратегии: как организация с сильным продуктом и слабой упаковкой первого касания строит систему каналов, визуала и доказательств. Подходит как образец для малой команды.

## диагноз
Что было: сленг и ощущение междусобойчика, нет закрепов и подборок, линейка входа читается не сразу, нет прозрачной воронки из контента в продажи, охваты держатся на блоге основателя, холодная аудитория не получает сценария движения.
Что нужно: понятное позиционирование, вход для новичков и для сильных практиков, видео от основателя, команды и партнёров, каждый канал упакован, каждый материал ведёт к лид-магниту или боту. Сдвиг подачи: загадка → узнавание себя → объяснение → механика → доказательство → действие.

## позиционирование
Свободная территория: персональный контекст, живой эксперимент, сильные практики, рабочий артефакт, клубная культура. Пять опор: способ думать важнее инструментов, контекст как основа, AI как усилитель человека, обучение через создание, среда, которая даёт идее сопротивление. Семь ценностей (авторская позиция, трансформация, предпринимательский драйв, глубина, честность о сложности, открытый процесс, практика на себе) и восемь фирменных фраз задают голос.

## система площадок: у каждой одна работа
| канал | работа | путь |
|---|---|---|
| Instagram | визитка: карусели, метафоры, контент для пересылки | узнавание → сохранение → вход в воронку |
| Telegram | дневник основателя, кейсы, наблюдения | доверие → контекст → диалог |
| LinkedIn и Facebook | деловой контур: разборы и кейсы | экспертиза → контакт |
| YouTube | польза с первого касания: эфиры, простые темы | поиск → доказательство → длинное внимание |
| бот | маршрутизатор: кодовое слово, метки, выдача артефактов | слово → материал → шаг |
| e-mail | библиотека пользы, серия касаний | материал → серия → предложение |
| Luma | живой контакт: приглашения на события | приглашение → встреча → возвращение |
Общий путь: контент → узнавание → бот или материал → канал или эфир → лаборатория.

## визуальная стратегия
Чёрное поле, молочный свет, один красно-бордовый акцент. Правило лаборатории 70 / 20 / 10: 70% общая ДНК бренда, 20% цвет и образ лаборатории, 10% эксперимент кампании. Шесть приёмов: киноплакат плюс инженерное руководство, живой архив (плёночная фактура), метафора как переводчик, польза с характером, доказательство в открытую (кейсы учеников), эфир превращается в инструкцию. Рецепт единицы: одна фраза, один герой, одно вмешательство, один слой метаданных, один результат.

## Reels-воронка
Четыре типа: узнавание себя (заход с боли и внутренней реплики), польза, которую сохраняют, цифры в движении, артефакт по кодовому слову. Путь: Reels → комментарий → личное сообщение → бот → подписка → артефакт → продукт. Каждый ролик открывает проблему, показывает один ход и приводит к материалу.

## коллаборации
- Instagram: соавторство постов со спикерами, совместные прямые эфиры, единая метка и единый следующий шаг;
- Telegram: интервью в формате карточек, совместный эфир двух каналов, нативный пост через личный инсайт партнёра, история выпускника, общая папка каналов для основателей и операторов;
- протокол совместного эфира: за 5–7 дней тема, роли, призыв, площадка; за 2 дня первый анонс в двух каналах; за 1 день сбор вопросов отдельным постом; за 30–60 минут напоминание и закреп; после эфира запись, пять тезисов, ответы и продолжение темы;
- сценарий эфира на 45 минут: вход, первое правило, кто сидит за столом, проверка решений, выход с пятью признаками и следующим шагом.

## 90 дней
Дни 0–30 ясность: описание, закрепы, подборки, маршрут продукта, список доказательств, шаблоны. Дни 31–60 ритм: пилотные серии, воронка Reels, коллаборации, кейсы сообщества. Дни 61–90 масштаб: календарь коллабораций, атрибуция, лучшие форматы, генераторы.

## что сделать завтра на своём продукте
1. записать для каждого канала одну работу и один путь, как в таблице выше; лишнюю работу убрать;
2. выбрать один Reels или пост типа «артефакт по слову» и завести кодовое слово с меткой в ссылке ([[{rule} attribution first]]);
3. составить протокол одного совместного эфира по срокам «−7 / −2 / −1 / −1 час / после»;
4. написать сдвиг подачи для одного материала по цепочке «узнавание → механика → доказательство → действие»;
5. проверить материал по [[{rule} creative-codes]] и записать код в имя.
