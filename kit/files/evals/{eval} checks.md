# проверки кодом

Уровень 1 из [[{rule} evals]]: скрипт `bin/check.mjs`, без модели, секунды.

## что проверяет
| проверка | как | тип |
|---|---|---|
| длинное тире | символ U+2014 в тексте | провал |
| антитеза | «не X, а Y», «это не X – это Y», «вместо X – Y» | провал |
| стоп-слова | список из раздела «стоп-лист слов» [[{rule} anti-slop]] | провал |
| frontmatter | nucleus, channel, segment, code, status | провал |
| код креатива | формат `P1-H1-A1-F1` | провал |
| подушки | «стоит отметить», «секрет в том», «и вот что важно» | предупреждение |
| длина | LinkedIn 700–1700 знаков, Telegram 300–1600 | предупреждение |
| числа без источника | число с единицей, которого нет в [[{context} truth-pack]], `sources/`, `nuclei/` | предупреждение |
| ссылка в посте LinkedIn | ссылку переносим в первый комментарий | предупреждение |

## запуск
```bash
node bin/check.mjs            # отчёт evals/{eval} checks – <дата>.md, код выхода 1 при провале
node bin/check.mjs --golden   # регрессия на golden set перед правкой скилла или правила
node bin/check.mjs --json     # машинный вывод для агента
```

## правило пирамиды
если судья второй раз ловит то, что ловится регулярным выражением, проверка переезжает сюда.
