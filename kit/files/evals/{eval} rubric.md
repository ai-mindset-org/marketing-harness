# рубрика ворот

Черновик уходит человеку, когда закрыты пять ворот. Первые два проверяет код, остальные – судья.

| ворота | проверка | порог | уровень | где правило |
|---|---|---|---|---|
| чистота | длинное тире, антитеза, стоп-слова, подушки | 0 находок | код | [[{rule} anti-slop]] |
| форма | frontmatter, код креатива, длина по каналу | всё заполнено | код | [[{rule} naming]] · [[{rule} creative-codes]] |
| факты | каждая цифра и имя есть в источнике | 0 `факт?` | код + судья | [[{context} truth-pack]] · [[{skill} fact-check]] |
| голос | пять осей шкалы | ≥ 80 из 100 | судья | [[{rule} anti-slop]] · [[{context} voice]] |
| попадание | один сегмент, одна боль, один CTA, правила площадки | да | судья | [[{context} audience]] · [[{skill} linkedin-post]] |

Отчёты: код – [[{eval} checks]], судья – `evals/{eval} scorecard – <дата>.md`.
