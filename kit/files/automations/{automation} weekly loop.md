# автоматизация · пятничный срез

Недельная петля Кумара ([[{source} kumar creative machine – 2026-09-23]]) на наших каналах: снапшот единиц, вердикт по оплатам, пары параметров, решения на неделю. Уровень 4 из [[{rule} evals]]: рынок.

## паспорт
| поле | значение |
|---|---|
| расписание | пятница, 16:00 |
| исполнитель | рутина Claude Desktop, cron + `claude -p` или Сотник |
| скилл | [[{skill} weekly-loop]] |
| вход | выгрузка охватов, кликов, регистраций и оплат по `utm_content`; файлы `outputs/`; [[{eval} scorecard – 2026-09-29]] как образец |
| выход | `dashboards/{dashboard} weekly – <дата>.md` |
| побочный выход | строки в «выучено на ошибках» [[{rule} anti-slop]] и отрицательные примеры в [[{eval} golden-set]] |
| владелец | [[{role} marketer]] |
| планировщик | один: либо рутина, либо cron ([[{guide} automation]]) |

## запуск
```
0 16 * * 5 cd ~/harness/<имя> && claude -p "Прочитай AGENTS.md. По скиллу weekly-loop собери недельный срез: вердикт по каждой единице, пары сегмент × хук и хук × формат, сетку покрытия нуклеус × канал, решения на неделю. Вердикт ставь только единицам старше 10 дней." --allowedTools "Read,Write,Bash(node bin/*),Bash(git status),Bash(git add:*),Bash(git commit:*)" >> ~/.harness-logs/weekly-loop.log 2>&1
```
Оплаты по коду человек кладёт файлом в `sources/` до запуска ([[{rule} attribution first]]): без колонки оплат вердикт остаётся `testing`.

## что происходит с находками
1. критик нашёл одну и ту же ошибку в двух черновиках – скилл предлагает строку в `rules/{rule} anti-slop`;
2. плохой текст уходит в golden set отрицательным примером с пометкой, какое правило его ловит;
3. `node bin/check.mjs --golden` проверяет, что правка не сломала прежние примеры;
4. фаундер принимает или отклоняет строку правила, агент сам правила не меняет ([[{skill} harness-evolve]]).

## что делает человек
45–60 минут: прочитать срез, подтвердить вердикты, выбрать три решения на неделю (повторить, переписать хук, снять), принять или отклонить строки правил.

## стоимость
один прогон на среднем уровне модели; токены в пределах подписки. Платных сервисов нет.

## как выключить
пауза рутины или `#` перед строкой cron; срез можно собрать руками в сессии тем же скиллом. Запись в журнал запусков ([[{guide} automation]]).

## граница
Срез читает данные и пишет файл. Бюджеты, публикацию и решения о масштабе канала принимает человек ([[{rule} boundaries]]).
