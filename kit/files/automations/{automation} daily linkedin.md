# автоматизация · утренний цикл LinkedIn

Схема Сергея Булаева ([[{source} bulaev linkedin – 2026-09-25]]): каждое утро агент собирает свежие посты ICP и черновики комментариев, человек утверждает, публикует сервис или сам человек. Порядок и лимиты – [[{rule} linkedin soft outreach]].

## паспорт
| поле | значение |
|---|---|
| расписание | будни, 08:30 по времени автора |
| исполнитель | рутина Claude Desktop или cron + `claude -p` на своём компьютере |
| скилл | [[{skill} linkedin-engage]] |
| вход | список ICP (компании и люди по должностям), посты за 10 дней из HarvestAPI или Apify; без сервисов – 10–20 ссылок, которые человек положил в `sources/` |
| выход | `outputs/linkedin/{post} engage – <дата>.md`: ссылка · автор (должность) · черновик комментария · причина · статус `draft` |
| владелец | [[{role} marketer]] |
| планировщик | один: либо рутина, либо cron ([[{guide} automation]]) |

## запуск
Рутина Claude Desktop: проект = папка харнесса, расписание «будни 08:30», текст задачи ниже. Вариант cron:
```
30 8 * * 1-5 cd ~/harness/<имя> && claude -p "Прочитай AGENTS.md. По скиллу linkedin-engage собери список на модерацию: посты ICP не старше 10 дней, до 20 постов для реакции, черновики комментариев на 1-3 предложения. Ничего не публикуй." --allowedTools "Read,Write,Bash(node bin/*),Bash(git status),Bash(git add:*),Bash(git commit:*)" >> ~/.harness-logs/daily-linkedin.log 2>&1
```
Ключи `APIFY_TOKEN` и `HARVESTAPI_KEY` лежат в `~/.zshrc`, в cron их подтягивает `source ~/.zshrc` перед командой ([[{rule} boundaries]]).

## что делает человек
1. открывает файл списка (10 минут);
2. каждую строку одобряет, правит или вычёркивает; статус меняется на `approved`;
3. публикует комментарии сам или через Publora (официальный API LinkedIn) после одобрения;
4. лайкнувших в ответ и зашедших на профиль переносит в список реангейджа; коннекты – не больше 20 в день и 200 в неделю.

Комментарий без одобрения не уходит никогда: автоматические комментарии нарушают правила LinkedIn (Булаев, `[14:17]`).

## стоимость
- подписка Claude по плану, лимиты хватает на один прогон в день;
- HarvestAPI: демо у Булаева $20, поддержание около $1 в день;
- Publora: около $3–4 в месяц, 15 постов бесплатно;
- время человека: 10–15 минут в день.

## как выключить
- рутина: выключить в списке рутин Claude Desktop;
- cron: `crontab -e`, поставить `#` перед строкой;
- сервисы: отозвать ключи HarvestAPI, Apify, Publora на их сайтах.
Запись в журнал запусков: `off, <дата>, <причина>`.

## граница площадки
Без подов, без автокомментариев, без сбора профилей вне официальных API и условий сервиса. Персональные данные ICP не пушим в git. Профиль автора агент не меняет: [[{skill} linkedin-profile]] готовит текст, правит человек.
