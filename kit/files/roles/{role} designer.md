# роль · дизайнер

Человек, который держит визуал харнесса. Токены и шаблоны лежат в `design/`, рендер собирает `bin/render.mjs` без модели. Дизайнер делает так, чтобы агент собрал слайд без вопроса «а какой шрифт».

## зона
- `design/` – [[{design} system]], [[{design} carousel]], [[{design} linkedin]], [[{design} landing]];
- `design/assets/tokens.css` – цвета, шрифты, рамка, сетка; единственное место, где живут значения;
- превью и готовые файлы: HTML и PDF в `outputs/`, рядом с брифом.

## что правит руками
| что | как |
|---|---|
| токены | `design/assets/tokens.css`: `--paper`, `--ink`, `--star`, `--clay`; после правки `node bin/render.mjs all` и просмотр всех слайдов |
| шаблон карусели | правило раскладки в [[{design} carousel]]; в брифе агент пишет `*слово*` (подчёркивание) и `_слово_` (курсив) |
| превью LinkedIn | сгиб «…ещё» на 210 знаках, карточка ленты, [[{design} linkedin]] |
| лендинг | блоки до 60 слов, тёмная панель для главной схемы, [[{design} landing]] |
| штамп кода | жёлтая заливка только на первом и последнем слайде |
| обложки и фото автора | руками вне харнесса, файл кладётся рядом с брифом |

## команды
```
node bin/render.mjs carousel "outputs/carousel/{carousel} car-01 weekly loop.md"
node bin/render.mjs linkedin "outputs/linkedin/{post} li-01 fake winner.md"
node bin/render.mjs landing  "outputs/landing/{landing} harness kit.md"
node bin/render.mjs all --pdf
```
`--pdf` требует Playwright: [[{tool} playwright]]. Формат карусели 1080×1350, одна страница PDF на слайд.

## что решает только он
- новая версия токенов и дата, с которой она действует (правка идёт отдельным коммитом);
- допуск нового типа визуала: видео, обложка, баннер – сначала строка в `design/`, потом скилл;
- отказ от слайда, который ломает систему, даже если текст прошёл [[{rule} anti-slop]].

## что остаётся автору
текст слайда: 8–25 слов на слайд по [[{context} voice]], хук из [[{rule} creative-codes]]. Дизайнер правит форму, смысл возвращает автору.

## связь с агентом
роль агента-дизайнера – скилл [[{skill} carousel-brief]]: он готовит покадровый бриф, а рендерит скрипт. Цвета и шрифты агент берёт из токенов. Время дизайнера: 3–5 часов в неделю, из них час на пятничный просмотр пачки.
