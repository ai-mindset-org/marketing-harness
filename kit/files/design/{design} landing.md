# лендинг

Страница продукта в языке самого инструмента харнесса: JetBrains Mono, белый фон, рамки 1px, нумерованные панели `01 · …`, схема на сетке с глифами слоёв графа, один красный акцент на экран (подчёркнутое ключевое слово). Перед записью – квиз по [[{rule} onboarding quiz]].

## блоки
1. **навигация** – бренд и штамп кода;
2. **hero** – заголовок 2–4 строки с подчёркнутым словом, подзаголовок одним абзацем, мета: дата · формат · цена из [[{context} truth-pack]];
3. **схема на сетке** – `fig. 1`, как устроено в 4–6 шагах, у каждого шага глиф слоя (■ ◇ △ ○ ● ✚);
4. **для кого** – три карточки сегментов из [[{context} audience]];
5. **что уносите** – список результатов;
6. **как проходит** – шаги по неделям или часам;
7. **квиз** – 3 вопроса, одиночный выбор сразу ведёт дальше, «пропустить», ответы уходят в `utm_content`;
8. **вопросы** – раскрывающиеся;
9. **подвал** – код и подпись сборки.

## копия
`outputs/landing/{landing} <имя>.md`: frontmatter (title, code, cta_url) и разделы `## hero`, `## meta`, `## fig`, `## для кого`, `## что уносите`, `## как проходит`, `## квиз`, `## faq`, `## cta`. Формат строк описан в шапке `bin/render.mjs`.

## рендер
`node bin/render.mjs landing "outputs/landing/{landing} harness kit.md"` → HTML рядом. Публикация – по правилам хостинга своей команды; секретов в странице нет.

пример: `outputs/landing/{landing} harness kit.html`.
