# маркетинг-харнесс · {{product_short}}

Папка, в которой живёт маркетинг продукта. Агент читает [[AGENTS]] при каждом запуске, остальное подгружает по ссылкам. Человек пишет контекст и правила, агенты пишут в свои папки, всё идёт через git.

## шаг ноль · где живёт папка
- на своём компьютере, в обычной папке, под git. Dropbox и iCloud – для личных документов, рабочую папку харнесса туда не кладём: синк ломает git;
- Claude Code запускается внутри папки: `cd <папка> && claude`. Codex – так же: `codex`;
- Obsidian открывает ту же папку как vault и показывает граф, он нужен для чтения и навигации, агентам он не нужен;
- ключи живут в `~/.zshrc`, в папке их нет: [[{rule} boundaries]].

Полная установка: [[{guide} setup]]. Первый час по шагам: [[{guide} first-hour]].

## три маршрута
- **только чат** – копируй скиллы в проект claude.ai и работай с файлами руками по [[{guide} first-hour]];
- **терминал** – `claude` внутри папки, скиллы подхватываются из `.claude/skills` (зеркало `skills/`);
- **агенты** – несколько сессий параллельно, каждая пишет в свою ветку, живой граф в браузере, задачи на сервер через Codex.
