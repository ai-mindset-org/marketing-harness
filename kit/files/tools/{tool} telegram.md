# Telegram

**Зачем:** канал и чаты – основной русскоязычный канал когорты. Агент готовит пост, человек публикует. По умолчанию – черновик в нужном чате, отправка только по явной команде: [[{rule} boundaries]].

## два способа
**бот (просто, для канала).**
1. @BotFather → `/newbot` → имя → токен;
2. `export TELEGRAM_BOT_TOKEN=<токен>` в `~/.zshrc`;
3. бота – администратором канала с правом публикации;
4. бот публикует сразу: черновиков у ботов нет, поэтому публикация только по команде человека.

**свой аккаунт через MTProto (черновики).**
1. my.telegram.org → API development tools → `api_id` и `api_hash`;
2. библиотека Telethon, первый вход по коду из Telegram; файл сессии держим вне папки харнесса;
3. черновик в целевом чате (`SaveDraftRequest`) – человек видит его в поле ввода и отправляет сам;
4. одна сессия MTProto на один компьютер. Тот же файл сессии на втором компьютере или сервере запрещён: Telegram отзовёт ключ. Для второго хоста заводи отдельную сессию;
5. агент сам в каналы не публикует: сначала черновик, отправка по команде человека.

## проверка
бот: `curl -s "https://api.telegram.org/bot$TELEGRAM_BOT_TOKEN/getMe" | python3 -c "import sys,json;print(json.load(sys.stdin)['result']['username'])"` печатает только имя бота, токен не показывается. Токен в адресе curl остаётся в истории оболочки, при необходимости очисти её.

## формат
строчные в начале блоков, короткое тире, без эмодзи, 500–1500 знаков: [[{context} voice]].
