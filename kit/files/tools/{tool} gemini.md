# Gemini

**Зачем:** модель, которая читает видео и картинки целиком. Кумар раскладывает чужие ролики на персону, хук, боди, энгл, эктора и формат; Урбан описывает ролик по секундам через Vertex AI. В харнессе – разбор креативов для [[{skill} adlib-recon]] и [[{skill} trendwatch]], второе мнение в [[{skill} cross-llm-verify]].

## где включить
- лично: aistudio.google.com → Get API key → `export GEMINI_API_KEY=<ключ>`;
- для больших квот: Vertex AI в своём проекте Google Cloud (оплата по счёту проекта);
- модель выбирать по текущему каталогу AI Studio: быстрая для сканов, старшая для покадрового разбора.

## проверка
`curl -s -H "x-goog-api-key: $GEMINI_API_KEY" https://generativelanguage.googleapis.com/v1beta/models | head` – список моделей. Ключ передаём заголовком: в адресе он остаётся в истории и логах.

## стоимость
разбор ролика стоит центы; пачка из 50 роликов на старшей модели – доллары. лимит на прогон ставим в скилле.
