# Codex и Сотник

**Зачем:** второй агент. Читает [[AGENTS]] сам, скиллы видит из `.agents/skills` (зеркало `skills/`). Удобен для кода харнесса: `bin/`, шаблоны дизайна, MCP. Кумар и Урбан держат Codex рядом с Claude: Codex пишет движки и проверяет выводы другой модели.

## локально
1. аккаунт ChatGPT (Plus, Pro, Business) или ключ OpenAI API;
2. установка: `npm install -g @openai/codex` или `brew install codex`;
3. вход: `codex login`;
4. работа в папке: `cd <папка> && codex`; без вопросов: `codex exec --full-auto "задача"`.

## Сотник
Для команды AI Mindset есть серверный запуск через консоль харнесса, участникам он не нужен.

## проверка
`codex --version` – версия есть.

## модель
новые задачи – текущая средняя модель из каталога Codex, средний уровень рассуждения; старшая – для сложной архитектуры, потом обратно.
