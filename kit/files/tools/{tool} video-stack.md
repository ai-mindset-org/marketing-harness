# видео-стек

Набор сервисов, которыми спикеры спринта собирают ролики. Харнесс держит текстовую часть (сценарий, раскадровка, промпты), видео собирается в этих сервисах руками или их API.

| сервис | роль | кто показывал |
|---|---|---|
| Higgsfield | маркетплейс моделей: первый кадр (Image), оживление (Video); годится для единичной идеи, для потока – нет | Кумар, Урбан |
| Seedance | качество «кино», предметы в кадре | Кумар |
| Veo 3 | видео с озвучкой, чаще для креативов и SMM | Кумар |
| Kling | дешёвые вставки, слабо с предметами | Кумар |
| CapCut | склейка сцен | Кумар |
| Weavy | нодовая доска: ролик раскладывается на фон, человека, текст, музыку; пересборка залетевшего ролика заменой лица и фона | Урбан |
| Vertex AI (Gemini) | описание чужого ролика по секундам | Урбан |

## конвейер
сценарий → [[{skill} raskadrovka]] (кадр каждые 3 секунды) → первый кадр → оживление → склейка → код креатива ([[{rule} creative-codes]]) → [[{skill} weekly-loop]].

## где включить
у каждого сервиса – аккаунт и оплата на своём сайте; ключи API (если есть) – в `~/.zshrc`. стоимость у Кумара: токены $10–12 за креатив, с работой креатора около $30 ([[{context} truth-pack]]).
