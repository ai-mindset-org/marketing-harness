# Exa

**Зачем:** поиск по смыслу для исследователя: рынок, конкуренты, практики, данные с датами. Скилл [[{skill} research-exa]].

## где включить
1. dashboard.exa.ai → API Keys → создать ключ;
2. в `~/.zshrc`: `export EXA_API_KEY=<ключ>`, перезапустить терминал;
3. `.mcp.json` папки уже описывает сервер: `https://mcp.exa.ai/mcp?exaApiKey=${EXA_API_KEY}&tools=…`;
4. без ключа: `claude mcp add --transport http exa https://mcp.exa.ai/mcp` и вход через браузер. Такой вход слетает раз в несколько дней, для стабильной работы нужен ключ;
5. Codex: отдельная запись сервера в `~/.codex/config.toml`, подстановка переменных из `.mcp.json` там не работает;
6. ключ внутри URL сервера Claude сохраняет открытым текстом в своём конфиге (`~/.claude.json`): этот файл не публикуем и не отправляем.

## инструменты
| инструмент | когда | цена |
|---|---|---|
| web_search_exa | быстрый вопрос, 5–10 ссылок | дёшево |
| web_search_advanced_exa | фильтры: даты, домены, категории company · people · news · github | дёшево |
| web_fetch_exa | дочитать 2–3 лучшие страницы | дёшево |
| agent_run | список сущностей по схеме: 50 конкурентов с ценой и каналом | заметно дороже, только по решению человека |

## рецепт скана за 20 минут
1. цель одной фразой и что считаем ответом;
2. четыре запроса с разных сторон: рынок, конкуренты, данные и исследования, практики (github, блоги практиков);
3. фильтр по дате: 6–9 месяцев для платформ и алгоритмов;
4. запрос описывает идеальную страницу: «разбор 40 000 постов LinkedIn с цифрами охвата по форматам»;
5. три лучшие страницы дочитать;
6. у каждого утверждения ссылка, дата и уровень: A – официальный источник или данные из нескольких мест, B – одно исследование с методикой или открытый код, C – опыт практика;
7. итог – `research/{research} <тема> – <дата>.md`: таблица и блок «что это значит для нас»;
8. перекрёстная проверка другой моделью для важных выводов: [[{skill} cross-llm-verify]].

## проверка
в сессии `/mcp` → `exa · connected`; тестовый запрос «последние изменения алгоритма LinkedIn» возвращает ссылки с датами.
