# Claude Code

**Зачем:** основной агент харнесса. Читает [[AGENTS]] через `CLAUDE.md`, видит скиллы из `.claude/skills`, подключает MCP из `.mcp.json`.

## где включить
1. подписка Claude Pro или Max на claude.ai (или ключ API в console.anthropic.com для оплаты по токенам);
2. установка на мак и Linux: `curl -fsSL https://claude.ai/install.sh | bash`. Запасной путь через npm (`npm install -g @anthropic-ai/claude-code`) нужен только если нативная установка не работает: две установки рядом конфликтуют, оставь одну;
3. Windows: инструкция для Windows на сайте Claude Code (docs.claude.com);
4. в терминале: `cd <папка харнесса> && claude`, при первом запуске – вход через браузер;
5. Claude Desktop умеет то же в окне: проект = эта папка.

## проверка
- `claude --version` – версия есть;
- в сессии набери `/` – в списке видны скиллы проекта (`content-factory`, `slop-check` и другие);
- `/mcp` – серверы `exa` и `lms` в статусе connected. Они появляются только после `export` ключей в `~/.zshrc` и запуска нового терминала.

## разрешения
`/permissions`: разрешить запись в папку, `node bin/*`, `git status`, `git diff`. Публикацию и сеть держим через MCP с явным списком: [[{rule} boundaries]].

## ежедневный запуск
Claude Desktop умеет рутины (запуск по расписанию), так Булаев запускает утренний цикл LinkedIn. В харнессе рутина вызывает скилл, человек получает список на модерацию.

## стоимость
по подписке – в пределах лимитов плана; по API – по токенам. Длинные прогоны агентов держим на средней модели, сложные – на старшей.
