# Obsidian

**Зачем:** читать и навигировать папку харнесса, видеть граф связей. Агентам Obsidian не нужен: они работают с файлами напрямую.

## где включить
1. скачать с obsidian.md, бесплатно;
2. «Open folder as vault» → папка харнесса;
3. Settings → Files and links → «Automatically update internal links» – включить: при переименовании ссылки правятся сами ([[{rule} naming]]);
4. Graph view: цвета по веткам уже заданы в `.obsidian/graph.json`.

## как не утонуть
- одна папка харнесса – один vault; личные заметки держим отдельно;
- плагины по нужде: Dataview (таблицы из frontmatter), obsidian-git (коммиты из окна);
- синхронизация: git. Obsidian Sync и Dropbox для этой папки не используем, они спорят с git.

## проверка
открой [[README]] и нажми на любую ссылку `[[…]]` – файл открывается; граф показывает ветки разными цветами.
