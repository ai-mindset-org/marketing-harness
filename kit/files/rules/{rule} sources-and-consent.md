# источники и согласия

- у каждого нуклеуса поле `source`: файл в `sources/` или `research/`;
- цитата клиента идёт дословно, с согласием, без имени;
- цифра из чужого кейса подписывается владельцем: «у SternMeister», «у Кумара»;
- транскрипт личного разговора в `sources/` не кладётся;
- выгрузка из LMS несёт идентификатор сессии и дату, имена скрыты;
- внешнее утверждение из `research/` несёт дату публикации и уровень доказательства A/B/C по [[{tool} exa]].

Факты для текстов сводятся в [[{context} truth-pack]]. Проверка «сообщённое, а не сгенерированное» – [[{rule} principles]], пункт 9.
