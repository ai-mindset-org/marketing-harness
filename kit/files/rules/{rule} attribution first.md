# атрибуция раньше креативов

Оба практика спринта ставят атрибуцию условием масштаба. Урбан собрал свою (отпечаток устройства при скачивании и открытии, «почти сто процентов» склейки) и отдаёт площадке чистые данные. Кумар не доверяет площадке и сам сшивает, что кому показано. Вывод общий: без атрибуции не масштабировать.

## минимум для харнесса
1. у каждой единицы контента код из [[{rule} creative-codes]];
2. код уходит в `utm_content` каждой ссылки;
3. регистрации и оплаты сводятся по коду раз в неделю ([[{skill} weekly-loop]]);
4. вердикт ставится по оплатам; дешёвый лид без оплаты – fake winner;
5. пока оплаты не сведены, новый канал не масштабируем.
