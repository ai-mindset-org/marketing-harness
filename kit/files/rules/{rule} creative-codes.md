# коды креатива

Код = `P-H-A-F`. Пример: `P1-H1-A2-F2` – B2B-консультант, хук «цифра», энгл «как устроено», формат «документ-карусель». Код стоит во frontmatter черновика и в `utm_content`, поэтому регистрации и оплаты потом группируются по хуку и энглу. Кумар зашивает код в имя объявления (`P2-H1-B3-A5-UGC-COM`), кабинет отдаёт результат по имени.

## P · сегмент
по [[{context} audience]]: P1 B2B-консультант · P2 B2C-владелец · P3 технический основатель

## H · хук (первые две строки)
| код | хук | пример начала |
|---|---|---|
| H1 | цифра | «40 креативов в день, $10–12 на каждый» |
| H2 | сцена | «таргетолог говорит дизайнеру: лучше заходят коты» |
| H3 | признание ошибки | «колонка оплат у нас долго стояла пустой» |
| H4 | вопрос читателя | «где держать папку с контекстом?» |
| H5 | спор с общим мнением | «дешёвый лид – плохая новость, пока нет оплаты» |
| H6 | результат участника | с согласием и цифрой |

## A · энгл (чем убеждаем)
A1 проблема · A2 как устроено · A3 социальное доказательство · A4 до/после · A5 история основателя · A6 срочность

## F · формат
F1 текстовый пост · F2 документ-карусель · F3 короткое видео · F4 анонс эфира · F5 посев · F6 письмо · F7 лендинг-блок
