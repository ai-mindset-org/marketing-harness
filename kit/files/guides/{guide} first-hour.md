# первый час · три шага

Формат практики воркшопа: все делают одновременно, после каждого шага двое показывают экран. Нужен один свой текст о продукте: транскрипт, пост или описание.

## шаг 1 · контекст (12 минут)
в папке харнесса:
> прочитай AGENTS.md. задай мне семь вопросов анкеты по одному и разложи ответы в context/: product, audience, voice, truth-pack. цифры – только те, что я назвал.

результат: четыре файла в `context/`. проверка – агент пересказывает продукт и сегменты своими словами без ошибок.

## шаг 2 · нуклеусы (15 минут)
положи свой текст в `sources/{source} <что это> – <дата>.md` и скажи:
> по скиллу nucleus-extract вынь 3–5 нуклеусов из этого источника

результат: `nuclei/{nucleus} n01 …`. проверка – у каждого нуклеуса есть поле `source` и дословное доказательство.

## шаг 3 · пост и критик (15 минут)
> по скиллу linkedin-post (или пост для Telegram по голосу) сделай черновик из нуклеуса n01, потом node bin/check.mjs, потом slop-check в отдельном агенте

результат: черновик в `outputs/`, отчёт проверок в `evals/`, балл судьи. проверка – балл ≥ 80 и ноль `факт?`.

## после
- `git add -A && git commit -m "первый час"`;
- домашка к демо-дню: пачка из трёх черновиков с кодами и первый недельный срез ([[{skill} weekly-loop]]).
