# adlib-recon

скилл Ромы Кумара (занятие 23.09), полный промпт сборки – «Kumar Adlib Recon Prompt» в программе спринта.

- вход – бренды, домены, `page_id` или таблица;
- Playwright выкачивает Ads Library ([[{tool} playwright]]), ответы graphql перехватываются, срок открута считается сам; официальный API коммерческую рекламу не отдаёт;
- долгоживущий креатив (открут 90+ дней, только перформанс) считается проверенным рынком;
- Gemini раскладывает ролик на персону, хук, боди, энгл, эктора и формат ([[{tool} gemini]]);
- выход – рейтинг креативов по сроку и каталог механик «у всех · у единиц · ни у кого».

быстрый вариант без сборки – готовый сборщик Ads Library в [[{tool} apify]]. результат раскладывается по кодам [[{rule} creative-codes]] и идёт сырьём в [[{skill} nucleus-extract]].
