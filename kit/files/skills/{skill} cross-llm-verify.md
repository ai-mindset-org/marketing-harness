# cross-llm-verify

механика Кумара (23.09): Codex зовёт Claude и Gemini, Claude зовёт остальных; каждая модель видит одни и те же источники.

1. вход – файл из `research/` или разбор; выход – список сомнительного.
2. вторая модель получает только текст вывода и ссылки, без рассуждений первой.
3. проверка: ссылка открывается и содержит утверждение; цифра совпадает с источником; вывод следует из данных.
4. у каждого пункта статус: подтверждено · расходится (с цитатой) · не найдено.
5. результат дописывается в конец проверяемого файла блоком «сверка другой моделью, <дата>».

как запускать: Claude-сессия вызывает `codex exec` или Gemini через [[{tool} gemini]]; Codex-сессия – наоборот ([[{tool} codex]]).
