# content-factory

конвейер: нуклеус → матрица форматов → черновики → проверки → срез.

1. возьми нуклеусы без черновика из `nuclei/`.
2. для каждого выбери 1–3 формата по полю `форматы`, каналам из [[{context} product]] и сегменту.
3. LinkedIn – [[{skill} linkedin-post]], карусель – [[{skill} carousel-brief]], B2C-неделя – [[{skill} b2c-week]], Telegram – по [[{context} voice]].
4. frontmatter по [[{rule} naming]]: nucleus, channel, segment, code, status: draft.
5. `node bin/check.mjs` – проверки кодом. упало – исправь сам, потом отдавай дальше.
6. отдай пачку [[{skill} slop-check]] в отдельном контексте. балл ниже 80 – одна переписка и повторная проверка, после второй неудачи черновик уходит человеку.
7. `node bin/render.mjs all` – дизайнер собирает карусели, превью LinkedIn и лендинг.
8. строки пачки – в недельный срез ([[{skill} weekly-loop]]).

## органика как поставщик
залетевшая единица (вердикт winner) → 3–5 вариаций с тем же хуком и новым энглом: [[{rule} organic content factory]].

## параллельно
ресёрч, нуклеусы, черновики и рендер могут идти разными агентами; у каждого своя папка записи ([[{rule} principles]], пункт 5).
