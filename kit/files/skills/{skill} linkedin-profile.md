# linkedin-profile

профиль – лендинг автора: на него приходят из комментариев и постов, решение о коннекте принимается здесь. агент готовит тексты, меняет профиль человек.

1. шапка (headline, до 220 знаков): кому помогаю + результат + доказательство. без «визионер» и «евангелист».
2. about (до 2600 знаков): первая строка – боль ICP из [[{context} audience]]; дальше механизм, два кейса с цифрами из [[{context} truth-pack]], один CTA.
3. featured: 2–3 элемента – лучший документ-пост, кейс, лид-магнит.
4. лид-магнит: полезный файл для ICP (чек-лист, шаблон, выложенный скилл); выдаётся по ссылке, без «напиши слово в комментариях».
5. опыт: одна строка результата на позицию.

выход – `outputs/linkedin/{post} profile <дата>.md` с блоками для копирования. проверка – [[{rule} anti-slop]].
