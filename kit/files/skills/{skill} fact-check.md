# fact-check

стандарт «сообщённое, а не сгенерированное»: каждое утверждение показывает на источник ([[{rule} principles]], пункт 9).

1. выпиши из черновика все утверждения: цифры, имена, даты, «исследования показывают».
2. каждое сверь с [[{context} truth-pack]], `sources/`, `research/`. нашлось – сноска с файлом и таймкодом.
3. не нашлось – пометка `факт?` и одно из трёх: найти источник, смягчить до мнения автора, удалить.
4. по схеме Булаева для важного поста: «докажи, что это чушь» – попроси агента опровергнуть тезис; три независимых источника на ключевой факт.
5. отчёт – строкой в `evals/{eval} scorecard – <дата>.md`: файл · утверждений · с источником · `факт?`.

проверка кодом делает шаг 2 для чисел автоматически: [[{eval} checks]].
