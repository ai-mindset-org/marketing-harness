# weekly-loop

недельная петля Кумара, перенесённая на наши каналы. уровень 4 из [[{rule} evals]]: рынок.

1. снапшот: каждая единица × охват × клики × регистрации × оплаты по коду из `utm_content` ([[{rule} attribution first]]).
2. вердикт: winner · fake_winner · loser · testing. бенчмарк единицы – 10–14 дней, раньше ставим testing.
3. одна строка решения на единицу: повторить, переписать хук, снять.
4. пары параметров: сегмент × хук, хук × формат – какие выигрывают.
5. `dashboards/{dashboard} weekly – <дата>.md`: таблица, сетка покрытия нуклеус × канал, решения на неделю.
6. находка критика, встреченная дважды, – строка в «выучено на ошибках» [[{rule} anti-slop]] и отрицательный пример в [[{eval} golden-set]].

справка по платной рекламе (Кумар, если есть Meta Ads): тест решается на 2000 показах по двум метрикам, креатив без нужной цены лида три дня отключается, сильная кампания получает +20% бюджета.
