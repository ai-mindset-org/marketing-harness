# research-exa

1. прочитай [[{tool} exa]], сформулируй цель одной фразой и что считаешь ответом.
2. четыре запроса через `web_search_advanced_exa` с разных сторон (рынок, конкуренты, данные, практики), фильтр по дате 6–9 месяцев.
3. дочитай 3 лучшие страницы через `web_fetch_exa`.
4. запиши `research/{research} <тема> – <дата>.md`: таблица «утверждение · источник · дата · уровень A/B/C», блок «что это значит для нас» со ссылками на [[{context} audience]] и [[{context} product]].
5. важный вывод прогони через [[{skill} cross-llm-verify]].
6. `agent_run` не запускай без слова человека.

## режим «адвайз-пак» (по Кумару)
сбор лучших практик одной темы (продажи, посадочные, копирайтинг, A/B-тесты) из книг, Reddit, X и YouTube за год: 30–150 тактик, у каждой – источник и условие применимости. файл `research/{research} advice <тема> – <дата>.md`.

выход – сырьё для [[{skill} nucleus-extract]].
