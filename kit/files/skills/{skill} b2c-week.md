# b2c-week

для сегмента P2 из [[{context} audience]]: органика держится на одном человеке, непонятно, какие идеи создают спрос.

1. вход: 5–10 позиций каталога или услуг (что, цена из [[{context} truth-pack]], история, фото) и календарь поводов недели.
2. на неделю – 5–7 единиц: история вещи, повод, отзыв с фото (с согласием), «как выбрать», закулисье, подборка, короткое видео.
3. у каждой единицы код из [[{rule} creative-codes]] и один CTA; продукт в кадре неявно ([[{rule} organic content factory]]).
4. короткое видео – сценарий 15–30 секунд, дальше [[{skill} raskadrovka]].
5. файл `outputs/telegram/{post} b2c week – <дата>.md` таблицей: день · единица · канал · код · текст · визуал.
6. в пятницу – вердикт по оплатам: [[{skill} weekly-loop]].
