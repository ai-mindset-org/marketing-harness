# raskadrovka

скилл Ромы Кумара (занятие 23.09), полная версия – «Kumar Raskadrovka RU» в программе спринта.

железные правила:
1. таблица «таймкод · кусок сценария · визуал в кадре»;
2. кадр меняется каждые 3 секунды;
3. персонажи яркие, фон приглушённый;
4. в анимации движение резкое, у говорящей головы жест совпадает со словом;
5. отдельный блок «описание персонажей»;
6. без субтитров в кадре, в каждой строке звучит реплика, музыка или звук;
7. референс приоритетнее правил: стиль, палитра, типаж берутся из него.

дальше: первый кадр → оживление → склейка ([[{tool} video-stack]]).
