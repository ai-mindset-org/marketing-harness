# slop-check

уровень 2 из [[{rule} evals]]: судья. уровень 1 (код) уже прошёл: `node bin/check.mjs`.

1. прочитай [[{rule} anti-slop]], [[{context} voice]], [[{eval} rubric]] и промпт судьи [[{eval} judge]].
2. на каждый черновик: находки из стоп-листов с цитатой, пять оценок по шкале, балл из 100.
3. сверь цифры и имена с [[{context} truth-pack]]: чего нет – `факт?`.
4. строка в `evals/{eval} scorecard – <дата>.md`: файл · балл · находки · вердикт pass/rewrite.
5. текст не переписывай: правку делает автор, ты показываешь место.

находка в двух черновиках – запиши в scorecard раздел «предложения»: строку для «выучено на ошибках» [[{rule} anti-slop]] и отрицательный пример для [[{eval} golden-set]] с уровнем (`golden fail`, если ловит код, `golden judge`, если только судья). сам `rules/` и golden set не правь: их меняет [[{skill} weekly-loop]] после согласия человека. для русского голоса AIM есть лаборатория голоса Миши (`voicelab check`) – тот же принцип, свой стек проверок.
