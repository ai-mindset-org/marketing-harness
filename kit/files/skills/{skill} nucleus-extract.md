# nucleus-extract

из одного источника – 3–7 нуклеусов. нуклеус = одна мысль, которую можно проверить по источнику.

файл `nuclei/{nucleus} nNN <slug>.md`:
```
---
id: nNN
source: "[[имя файла источника]]"
timecode: мм:сс
segment: P1|P2|P3
confidence: high|medium|low
---
# тезис одной строкой
- триггер: когда читатель узнаёт себя
- доказательство: дословно из источника, с таймкодом
- шаг: что сделать завтра
- контр-тезис: где это не работает
- форматы: F1 · F2 · F4
```

правила: цифры только из источника – [[{rule} sources-and-consent]]; без длинного тире и антитез уже на этом шаге ([[{rule} anti-slop]]): слоп в нуклеусе переедет в каждый черновик.
