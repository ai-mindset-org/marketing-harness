# словарь

## шесть слов для старта
| слово | что это | где в папке |
|---|---|---|
| харнесс | папка с контекстом и правилами, внутри которой работает агент | вся папка, вход – [[AGENTS]] |
| контекст | правда о продукте, аудитории, голосе и фактах | `context/` |
| скилл | рецепт одной задачи; грузится, когда задача совпала с описанием | `skills/` |
| агент | модель, которая работает по скиллу и пишет в свою ветку | Claude Code, Codex |
| нуклеус | одна проверяемая мысль из источника | `nuclei/` |
| критик | агент, который проверяет текст в отдельном контексте | [[{skill} slop-check]] |

## дальше
- **MCP** – способ подключить к агенту внешний инструмент: поиск Exa, LMS. настройка в `.mcp.json`;
- **eval** – проверка качества: код, судья, человек, рынок. принцип – [[{rule} evals]];
- **golden set** – эталонные примеры «хорошо» и «плохо», на которых проверяют правку скилла;
- **truth-pack** – список фактов, которые можно называть;
- **код креатива** – `P-H-A-F`: сегмент, хук, энгл, формат;
- **зеркало** – копия скиллов, которую видит конкретная программа; правится только источник;
- **срез** – недельная таблица единиц контента с вердиктами.

Незнакомое слово – спроси агента: «объясни на примере этой папки».
