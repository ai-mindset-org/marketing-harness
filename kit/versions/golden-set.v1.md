# golden set

Эталонные примеры: хорошие должны пройти проверки, плохие – упасть. Перед правкой скилла или правила: `node bin/check.mjs --golden`. Правка, которая ломает пример, не принимается ([[{rule} evals]], правило 3). Каждый провал, найденный человеком или рынком, добавляется сюда отрицательным примером.

## хорошие
```golden pass
у нас в таблице посевов колонка оплат долго стояла пустой. цену лида мы знали по каждому размещению, оплаты – почти ни по одному.
```

```golden pass
первый конвейер – креативы: сценарий, раскадровка, первый кадр, оживление, склейка. 40 креативов в день.
```

## плохие
```golden fail: антитеза, стоп-слово
это не просто инструмент, а революционный подход к маркетингу.
```

```golden fail: длинное тире
контент — это топливо, воронка — это двигатель.
```

```golden fail: подушка
стоит отметить, что LinkedIn меняет алгоритм каждый год.
```
