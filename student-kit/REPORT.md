# Отчёт о добавлении микрохарнесса

## Что найдено

В репозитории уже есть полноценный маркетинг-харнесс спринта n25 (`kit/`) и сайт-инструмент (`web/`) с Demo, Local и Team. Шаблон дизайн-системы расположен как отдельная страница сайта. Задачи про лиды, общее устройство сайтов, редактор страниц и QA выходят за пределы текущего сценария спринта, поэтому они вынесены в самостоятельную папку `student-kit/` без изменения существующих фаз и сайта.

## Что добавлено

| Раздел | Готовый материал | Что нужно заполнить команде |
|---|---|---|
| `lead-to-bot/` | локальный HTTP relay, dry-run, Telegram adapter, тесты и схема доставки | домен формы, серверный хостинг, bot token и chat ID в секретах, очередь, мониторинг |
| `shared-sites/` | схема parent/child, пример pin и контракта настроек | реальные репозитории, SHA родителя, renderer и CI |
| `editable-pages/` | две страницы, команда создания третьей, runtime и CSS из `site-edit-overlay-builder`, сохранение в общий append-only журнал, локальный сервер и тесты | контент, список блоков, права редакторов, статический экспорт |
| `qa-dashboard/` | статический обзор с синтетическим `report.json` | агент проверок, хранилище истории, приватность отчётов, публикация |
| `AGENTS.md` | маршрут для следующего агента | владельцы и правила конкретного проекта |

## Что проверено и что не заявляется

Примеры не содержат токенов, реальных получателей, лидов и QA-снимков. Локальные тесты проверили формат данных, сухой прогон relay, отказ чужому origin, HTML escaping и рендер двух страниц. Новый overlay проверен в браузере на копии данных: прямое изменение заголовка, текста кнопки и общего имени, сохранение в журнал, обновление обеих страниц, перестановка списка и разделов с навигацией, ответ `409` для устаревшей ревизии, мобильная ширина 390 px. Изменения одной страницы не меняют порядок другой. Ни один файл из `student-kit/` не включён автоматически в `kit/`, Demo, архив или действующий сайт. Живую доставку Telegram, облачный деплой и QA-инфраструктуру надо настраивать для конкретной команды.

Под «Кией/кидашбордом» в этом наборе понимается AIM Site Agent Evaluation / QA Dashboard. Это рабочее допущение до уточнения названия у владельца.

Для просмотра создан локальный launcher: `marketing-harness/! Open Marketing Student Kit.command` → `_ Marketing Harness Student Kit.app` в папке проекта AI Mindset. Иконка собрана из `docs/social-preview.png` → `AppIcon.icns`; исходный PNG оставлен на месте. Откат локального launcher: переместить `.app` в macOS Trash, затем переместить `.command` в Trash. Исходники набора откатываются отдельным git-коммитом; файлы не требуется удалять навсегда.

Перенос редактора: `$CODEX_HOME/skills/site-edit-overlay-builder/assets/editor-overlay-kit/site-edit-overlay-runtime.js` → `student-kit/editable-pages/overlay/site-edit-overlay-runtime.js`, аналогично для `.css`. Первый учебный сервер и его тесты сохранены перед заменой во временной папке локальной машины; исходная версия также остаётся в истории git.

## Следующий практический шаг для курса

Дайте студентам одно упражнение на каждый раздел: прогнать синтетический лид, обновить pin общего блока в учебном child repo, отредактировать текст страницы и разобрать один `fail` и один `unknown` в QA-отчёте. После этого каждая команда подставляет собственные значения по README выбранного раздела.
