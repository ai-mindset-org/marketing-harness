# Шаблон дизайн-системы

[Открыть страницу](./) · [реестр значений](template-values.json)

Это самостоятельный шаблон на основе структуры [AIM material system](https://aimindset-design.web.app/material-system/). Он сохраняет 21 раздел, 16 раскрываемых блоков, 29 показываемых цветовых ролей, девять ступеней типографики, три роли кнопок, четыре варианта строки, четыре типа карточки и три типа цитат. Отдельной страницы Wild здесь нет; общие правила графики и движения находятся в основном документе.

## Как заполнить для нового проекта

1. Заполните `template-values.json`: 36 цветовых ролей, семейства шрифтов, девять ступеней кегля, сетку, интервалы, движение и контент. `null` означает, что решение ещё не принято.
2. Замените учебные примеры и ссылки в `index.html` на собственный контент, сохранив роли компонентов и их состояния.
3. Перенесите утверждённые значения в семантические CSS-переменные файлов `aim-material-system.css`, `site/` и `components/`. Нейтральные цвета CSS служат только для предпросмотра незаполненного шаблона.
4. Проверьте контраст, фокус, мобильную ширину и `prefers-reduced-motion`. Выгрузка на странице выдаёт каркас с `<COLOR>`, `<FONT_FAMILY>` и `<SIZE>`.

Классы `aim-*` в нескольких перенесённых компонентах оставлены как технические селекторы. Они не задают бренд. Исходную дизайн-систему этот шаблон не изменяет.
