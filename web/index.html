    01 · папка в браузере

    выбери папку харнесса на компьютере или перетащи её сюда из Finder. граф строится из файлов, правки сохраняются прямо в них. без установки; агенты, сессии, откат и коммиты – в полном режиме. на телефоне папку не выбрать: подключай с компьютера.

    Chrome, Arc, Edge
    02 · полный режим: агенты, сессии, откат, форк, Obsidian

    в терминале: скачать движок и рабочую папку (уже скачанное пропускается) и обновить:

    [ -d ~/harness-engine ] || gh repo clone ai-mindset-org/marketing-harness ~/harness-engine; [ -d ~/harness/marketing-sprint ] || gh repo clone ai-mindset-org/marketing-harness-sprint ~/harness/marketing-sprint; git -C ~/harness-engine pull -q; git -C ~/harness/marketing-sprint pull -q

    запустить – откроется граф с консолью агентов; если уже запущен, просто откроется вкладка:

    ~/harness-engine/bin/open.sh ~/harness/marketing-sprint
    открыть localhost:4747 ↗если граф уже запущен; при занятом 4747 open.sh берёт следующий порт и пишет адрес в терминале

    свой харнесс с нуля: ~/harness-engine/bin/new.sh ~/harness/my-product b2b-consultant · копия с историей: ~/harness-engine/bin/fork.sh ~/harness/marketing-sprint ~/harness/my-try · остановить: ~/harness-engine/bin/stop.sh [порт] · нет gh: brew install gh && gh auth login
