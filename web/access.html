02 · как хранить ключ

просто: ~/.zshrc

echo 'export EXA_API_KEY=<ключ>' >> ~/.zshrc
source ~/.zshrc

новый терминал видит ключ; Claude Code и MCP подхватывают его при запуске.

надёжнее: связка ключей macOS

security add-generic-password -s EXA_API_KEY -a "$USER" -w
# в ~/.zshrc:
export EXA_API_KEY="$(security find-generic-password -s EXA_API_KEY -w)"

значение не лежит в файле открытым текстом.

что уходит в git

.mcp.json с ${EXA_API_KEY} на месте ключа. перед push – gitleaks detect --no-git --source .. ключ, вставленный в чат, считается засвеченным: перевыпусти.
